## C. 验收标准（货到检查）

### C8T6 核心板（×2）
- [ ] PCB 是蓝色或绿色均可
- [ ] USB Type-C 接口（非 Micro-USB）
- [ ] **8MHz 晶振 + 32.768KHz 晶振** 两个都在
- [ ] 排针已焊（不要自己焊 64 个脚）
- [ ] 上电后红色电源 LED 亮
- [ ] 绿色 PC13 LED 闪烁（如果烧录了示例程序）
- [ ] **BOOT0 跳线帽在 "0" 位置**（默认运行模式）

### NRF24L01+ 模块（×2）
- [ ] **黑色 PCB**（基础版，不是 PA+LNA 增强版）
- [ ] **板载 PCB 天线**（黑色蛇形走线）
- [ ] 排针已焊（8 pin 直插）
- [ ] 模块正面印 "Zave" 或类似店铺名（仿品也行，但 Zave 应该是正品）

### 电容
- [ ] 100µF：圆柱体，长引脚是**正极**（长正短负）
- [ ] 104：黄色/红色小方块，印 "104" + "25V"

## D. 兼容性警告

| 元件 | 兼容性 |
|---|---|
| **STM32F103C8T6** | 与 VET6 同系列，**代码完全兼容**（B.1 hello_uart 可直接移植）|
| **NRF24L01+** | Nordic 协议，**淘宝 99% 是 SI24R1 国产兼容**，可与 NRF24L01+ 互通 |
| **100µF 电容** | NRF24 电源储能，**容量 4.7µF ~ 100µF 都能用** |
| **104 25V 陶瓷** | 耐压 25V ≥ 6.3V，**所有 3.3V 电路通用** |
