## A. 项目 B 节点架构（异构传感网）

```
┌─────────────────┐  ┌─────────────────┐  ┌──────────────────────┐
│ 节点 1 (C8T6)   │  │ 节点 2 (C8T6)   │  │ 节点 3 (VET6 指南者)  │
│ + DHT11         │  │ + BNO055        │  │ 主节点（自带 LCD + DS18B20 + 光敏）│
└────────┬────────┘  └────────┬────────┘  └──────────┬───────────┘
         │                    │                       │
         └────────────────────┼───────────────────────┘
                              │ NRF24 2.4GHz
                              ↓
                    ┌──────────────────────┐
                    │ 网关 (ESP32-S3)      │
                    │ Wi-Fi → MQTT → OneNet│
                    └──────────────────────┘
```

### B.4 无源元件（NRF24 供电去耦）

| 元件         | 数量 | 状态    | 规格                         | 用途                       |
| ------------ | ---- | ------- | ---------------------------- | -------------------------- |
| 直插电解电容 | 4    | ❌ 待购 | **100µF 16V**（或 10µF 16V） | NRF24 电源储能，瞬时大电流 |
| 直插陶瓷电容 | 4    | ❌ 待购 | **104 = 0.1µF 25V**          | NRF24 高频去耦             |

> **为什么必须**：NRF24 发射瞬间电流 18-115mA，MCU 引脚供电能力只有 25mA。
> 不加去耦电容 → 通信丢包 5-10%；加上 → 丢包 < 0.1%。
> 这是面试官必问的工程细节。
